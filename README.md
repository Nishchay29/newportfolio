# Nishchay Tayal | AI/ML Developer Portfolio

A premium, modern, and interactive personal portfolio website designed with a futuristic AI/ML developer aesthetic. Built to showcase my skills, projects, and journey as a B.Tech CSE (AI & ML) student.

**[Live Demo](https://portfolio-three-ashy-bavr8kmk44.vercel.app/)**

## 🌌 Features
*   **Futuristic UI/UX:** A bespoke Charcoal + Violet design system with subtle glow effects and glassmorphic elements.
*   **Custom Interactive Cursor:** A custom-built cursor that smoothly follows the mouse and expands when hovering over interactive elements.
*   **Smooth Scroll Animations:** ScrollReveal.js integration for elegant, staggered fade-in animations as the user navigates the page.
*   **Fully Responsive:** Fluid layouts using CSS Grid and Flexbox, ensuring a perfect viewing experience across mobile, tablet, and desktop.
*   **Modern Typography:** Utilizes *Space Grotesk* for striking headings and *Inter* for highly readable body text.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure and accessible markup.
*   **CSS3:** Custom CSS variables for theming, advanced animations (keyframes, transitions), Flexbox, and Grid.
*   **Vanilla JavaScript:** DOM manipulation, custom cursor logic, and event handling.
*   **Libraries:** [ScrollReveal.js](https://scrollrevealjs.org/) for scroll-driven animations, [Remixicon](https://remixicon.com/) for scalable vector icons.
